# Video Backup AutoFix 2.0

Aplicación portátil para Windows, sin instalar Python ni FFmpeg. Interfaz oscura y compacta con seis espacios, sin balón ni animaciones decorativas.

Incluye visor reparado con reproducción, barra de tiempo y marcas de inicio/fin para exportar un tramo; proyectos UTF-8 `.toñadas`, guardado seguro y reapertura con referencias relativas a vídeos. Pantalla inicial para crear o abrir un proyecto.

Las pruebas Windows verifican interfaz, sincronización, reparación, audio, aspecto, recorte temporal, vista previa y guardado/reapertura de proyectos. También prueban el EXE sin herramientas externas en PATH. La vista previa es sin audio; la exportación conserva el audio principal.
